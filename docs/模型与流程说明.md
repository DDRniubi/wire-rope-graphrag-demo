# 模型与流程说明

## 组件

| 组件 | 包内位置或调用方式 | 作用 |
|---|---|---|
| 现场 YOLO | `models/site_yolo/best.pt` | 定位现场图像中的断丝候选框；权重训练名称为 `site_broken_wire_det_v6_hnm2`，记录的训练尺寸为 1280。 |
| DBTT YOLO | `models/dbtt_yolo/best.pt` | 公开数据集模型；权重训练名称为 `dbtt_broken_wire_pretrain2`，记录的训练尺寸为 800。完整流程只使用断丝类别 0。 |
| 千问视觉模型 | 百炼 API，`qwen3.5-omni-flash` | 接收 YOLO 标框图，描述表面、光照及框周围可见情况。 |
| 千问文本模型 | 百炼 API，`qwen-plus` | 整理图像结果，并从检索到的原文核对条目中选择依据。 |
| 文本向量模型 | 百炼 API，`text-embedding-v4` | 建库时产生文本向量；当前逐图关系排序不在线调用向量模型。 |
| Microsoft GraphRAG | 配置与脚本位于 `knowledge`，可选索引依赖见 `requirements-indexing.txt` | 从文档抽取实体关系、划分社区并建立索引。已生成索引直接随包提供。 |

YOLO 本地权重为实际模型文件。GraphRAG 是知识建库与检索框架，没有一个可以替代整个知识库的 `best.pt`。千问的云端模型权重不在本包中，运行在线流程需要调用方自己的账号。

## 当前知识库

来源：USACE《Wire Rope for Civil Works Structures》，EM 1110-2-3200，2016 年版，238 页英文 PDF。原文件哈希和下载地址记录在 `knowledge/source_manifest.json`。

实际索引规模：199 个分页文档、321 个文本块、1796 个实体、2741 条关系、349 个社区与349份社区报告。可视化只展示选出的关联子图，不能用屏幕上的节点数代表整个知识库规模。

## 完整执行顺序

1. 读取图片并复制到本次运行的 `source_images`，保留输入快照。
2. YOLO 输出断丝候选框、置信度、标框图及标签坐标。
3. 启用千问时，将标框图发送给视觉模型，保留描述和原始响应。
4. 合并检测与描述，生成图像事件和检测专用 Word 报告。
5. 从已有 GraphRAG 关系表匹配图像相关检查主题，沿关系定位到 PDF 页。
6. 千问文本模型选择相关原文核对条目，程序将条目的事实表述和页码写入逐图报告。
7. 生成综合 HTML，校验图片、关系 ID、原文哈希、引用页码及本地链接。

这一步运行时的检索是项目自己的关系排序逻辑，代码在 `knowledge/graph_retrieval.py`，没有调用 Microsoft GraphRAG 默认 local/global search。逐图报告当前使用已核对的 PDF 第78、80、121、130、131、136页作为候选来源，其中实际可写入的核对事实定义在 `REPORT_FACTS`。整本手册索引仍保留，可在后续扩展知识范围与问答方式。

## 结果文件

- `complete_demo.html`：综合展示入口。
- `pipeline_summary.json`：执行是否完成、使用哪个模型、是否调用千问等摘要。
- `detection/new_image_results.jsonl`：每张图的框和视觉描述。
- `detection/qwen_raw_responses`：视觉模型提示词和响应，仅在线运行产生。
- `detection/钢丝绳新图片检测报告.docx`：检测专用报告；GraphRAG 分析在下面的逐图报告中。
- `document_graphrag/reports`：图谱检索增强的逐图分析。
- `document_graphrag/traces`：图谱关系、原文、提示词、模型返回和选中事实。
- `document_graphrag/graph_demo`：图谱网页和 PDF 副本。
- `document_graphrag/graph_index`：用于本次报告的索引快照。

部分原始响应中会记录运行时的文件绝对路径，属于历史审计信息；展示链接和运行入口使用包内路径，复制后不需要访问原电脑。
