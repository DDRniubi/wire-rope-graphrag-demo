# 方案审阅与 demo 衔接要点

2026年10月23日核对了来稿《码头运维智能体多模态GraphRAG项目流程与评价方案》和当前完整包代码。总体流程可以保留，主要需要补充以下内容。

## 原方案需要调整的地方

1. **目标与现状分开。** 原第二节描述完整的文字、文档图片和表格联合检索。现有 demo 已实现照片检测、照片描述和手册文字图谱检索，尚未建立文档图表视觉索引、结构化表格检索和自由问答接口。修订稿在原步骤中增加了现状说明。
2. **照片输入与知识库多模态分开。** 现场照片经YOLO和千问处理，不等于PDF中的图片和表格已经参与检索。原图、派生标框图、参考示意图和表格必须保留不同证据角色。
3. **评价需控制生成方式。** 当前逐图报告从4类原文核对事实中选择，候选页也受限制，不能与开放生成直接比较正确率。保留其作为工程基线，正式方法对照统一生成协议。
4. **对照组与测试集具体化。** 增加文字、文字加图谱、文字加视觉、完整方案四组，冻结测试题和参数；同源图表、照片和改写题分组隔离。题库可引用已入库资料，但测试题、答案及标签不能进入索引。
5. **指标要有计算口径。** 补充证据单元与去重、等价证据集合、必要证据完整率、答案要点评分、引用支持与覆盖、页级和区域级定位，以及分阶段时间和实际用量。YOLO定位指标单独报告。

## 结合当前工程的改造顺序

先保留现有YOLO与报告入口，对现有手册做小批图表解析与来源区域定位；建立统一证据ID和人工核对题集。再添加自由问题入口、文字与视觉检索、可控图谱扩展及统一生成协议，最后运行对照实验。此时再判断需要增加哪些新算法，而不是先更换YOLO或扩大系统范围。

修订稿建议首轮60题，按题型分层安排20题开发、40题测试。这是拟定试点规模，没有新增测试结果。原流程图保留，正文四处加入Word修订说明批注，第四至第七节补充工程对应、改造路径、评价协议和实施顺序。
